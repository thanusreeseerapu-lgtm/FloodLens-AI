FloodLens AI

Satellite-Based Historical Flood Inundation Mapping and Geospatial Impact Dashboard

Problem

Historical flood mapping can help communities and disaster-management teams understand inundation patterns and identify potentially affected areas.

Project Goal

Develop a prototype that uses Sentinel-1 SAR satellite imagery to map historical flood extent and visualize potential impacts.

Planned Approach

- Obtain suitable pre- and post-flood satellite imagery.
- Explore VV/VH backscatter changes.
- Implement a baseline threshold-based flood mapping method.
- Build a geospatial dashboard using Streamlit.
- Evaluate results against reference data if suitable data is available.

Tools

- Python
- NumPy and Pandas
- Matplotlib
- Sentinel-1 SAR data
- Streamlit

Current Status

Project setup and data exploration are in progress. No model performance results are claimed yet.
